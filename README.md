# Frontend Jobs India (v1)

> **Note:** This is v1. The actively maintained version is [frontend-jobs-v2](https://github.com/deepu0/frontend-jobs-v2).

A job board for frontend developers in India, built with Next.js and Supabase.

## Tech Stack

- Next.js + TypeScript
- Supabase (PostgreSQL + Auth)
- Tailwind CSS
